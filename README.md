# Privacy policy: game music research tool

This private research tool uses YouTube API Services to read public video titles, descriptions and chapter lists, to note where music plays in video games.

- It does not access, collect or store any YouTube user's personal data, and it does not sign in as any user.
- Video text is kept for at most 30 days. Only short notes that cite video IDs are kept longer.
- It does not share any data with anyone.

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy: https://policies.google.com/privacy

Questions: open an issue in this repository.
